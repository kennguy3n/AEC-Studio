# Linux app icons

Drop platform-canonical PNGs here, sized 16/32/48/64/128/256/512.
electron-builder picks the right one for the AppImage and `.desktop`
file automatically.

Naming convention:
* `16x16.png`
* `32x32.png`
* `48x48.png`
* `64x64.png`
* `128x128.png`
* `256x256.png`
* `512x512.png`
* `aec-studio.svg` (optional vector source)

The icons are intentionally not committed yet — the project ships a
neutral placeholder until the studio supplies branded artwork.
